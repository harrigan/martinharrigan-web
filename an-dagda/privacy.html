Privacy policy

Effective 13 October 2026.

An Dagda is a personal application operated by Martin Harrigan. This policy says how it handles user data it receives from Google APIs.

What it accesses

An Dagda accesses only the Google user data that the signed-in account consents to on Google's consent screen, and only what its features need.

How it is used and stored

The data is used only to provide An Dagda's features to the account that granted access. It is stored on systems under its operator's control, together with the tokens Google issues, and is kept only for as long as those features need it.

Sharing

The data is not sold, shared with or transferred to anyone. It is not used for advertising, and it is not used to train any machine learning or artificial intelligence model.

An Dagda's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Any data held can be deleted on request to the address below.

Changes

This policy may change as An Dagda does; the date above says when it last did.

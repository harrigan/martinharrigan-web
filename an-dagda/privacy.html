Privacy policy

Effective 13 October 2026.

An Dagda is a personal application run by Martin Harrigan on his own machine, for his own use. This policy says what it does with data it reads from Google services.

What it reads

With the consent of the signed-in Google account, An Dagda requests read-only access to YouTube (https://www.googleapis.com/auth/youtube.readonly). It reads the list of videos that account has liked: each video's ID, title, channel name and publication date. It reads nothing else, and it never changes anything in the account.

How it is used and stored

The data is used only to keep a catalogue of videos watched, for the account owner's own reference. It is stored on the owner's own machine and nowhere else. The access token and refresh token Google issues are stored on the same machine and used only to read that list again when the owner asks.

Sharing

The data is not sold, shared with or transferred to anyone. It is not used for advertising, and it is not used to train any machine learning or artificial intelligence model.

An Dagda's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Any data held can be deleted on request to the address below.
